## 6. Common Errors and Resolutions

| Message | What it means | What to do |
|---------|---------------|------------|
| **Generated successfully** | The Factur-X invoice was created and attached. | Find the PDF in the invoice's Files. |
| **This invoice has no line items** | The invoice has no product/service lines. | Add at least one line item and try again. |
| **Invoice type is not valid** | The invoice type isn't set correctly. | Select a valid type (e.g. *Invoice* or *Credit Note*). |
| **VAT number must start with a country code** | A VAT number is missing its country prefix. | Edit the account's VAT number to include the country code (e.g. `FR…`). |
| **Registration number is not the right length** | The SIREN/SIRET is incomplete. | Enter a valid 9- or 14-digit number. |
| **Payment details look incorrect** | The IBAN, BIC, or payment method don't match. | Check the bank details on the payment account. |
| **A required field is missing** | Some mandatory information is incomplete. | The message lists what's missing — fill it in and retry. |

If a message isn't listed here, or it keeps appearing after you've made the correction, contact your administrator or support team.
