# Digital Invoice Glossary

## 8. Glossary

| Term | Meaning |
|------|---------|
| **Factur-X** | The French/European electronic invoice format: a PDF that is readable by both people and software. |
| **EN 16931** | The European standard that defines what a valid electronic invoice must contain. |
| **Seller / Payable To** | Your company — the party issuing the invoice. |
| **Buyer / Bill To** | Your customer — the party being invoiced. |
| **VAT number** | The tax identification number, written with its country code (e.g. `FR…`). |
| **SIREN / SIRET** | French company registration numbers (9 or 14 digits). |
| **IBAN / BIC** | Your bank account number and bank identifier, used so the customer knows where to pay. |
| **Tax breakdown** | The VAT summary by rate and category, calculated automatically from the invoice lines. |
| **Document template** | The layout that determines how the visual PDF looks. |
| **Tax template** | The tax configuration applied to an invoice. |
