# Solución de problemas

Aquí están los problemas comunes y cómo resolverlos:

| Problema | Causa probable | Solución |
|--------|---------------|----------|
| Error "Authorization required" | Permission set no asignado | Asigne el permission set `Mobee Data Connector` |
| No se devuelven resultados | Los filtros API son incorrectos o la API no está disponible | Verifique los valores de `API Query Filter`, pruebe la URL |
| Los campos mapeados no se rellenan | `API Field` incorrecto o discrepancia en el campo SF | Verifique las rutas y nombres de los campos |
