# Dépannage

Voici les problèmes courants et comment les résoudre :

| Problème | Cause probable | Solution |
|--------|---------------|----------|
| Erreur "Authorization required" | Permission set non attribué | Attribuez le permission set `Mobee Data Connector` |
| Aucun résultat retourné | Les filtres API sont incorrects ou l'API est indisponible | Vérifiez les valeurs de `API Query Filter`, testez l'URL |
| Les champs mappés ne se remplissent pas | `API Field` incorrect ou non-concordance du champ SF | Vérifiez les chemins et noms des champs |
